# 🧙‍♂️ Волшебники против Зомби — MVP

Математическая tower-defense игра для начальной школы в виде Telegram Mini App.
Ребёнок защищает замок от волн зомби: каждое заклинание — это пример, который нужно решить.
Между ночами волшебник и замок прокачиваются. Сложность заданий настраивается через админ-бота.

## Что есть в MVP

**Игра (Mini App)**
- Выбор класса (1–4) → стартовая сложность по каждой теме.
- Вертикальный экран: логическое поле 720×1280 вписывается в окно целиком, на широком экране — по центру.
- Арена: кладбищенские ворота наверху, две дорожки, замок и две сторожевые башни внизу. Зомби сначала атакуют башню своей дорожки, потом замок. Разрушен замок — поражение, все зомби повержены — победа.
- Панель примера всегда на экране. Мана (0–10) копится только за верные ответы: +3, быстрый (до 4 с) +4, серия от 3 подряд ещё +1. Ошибка показывает правильный ответ на секунду.
- Колода из 8 слотов с повторами (до 3 копий, пока открыто меньше 3 карт — без ограничения), в руке 4 карты. Карту можно перетащить на арену или нажать на неё, а затем на точку.
- 6 карт открываются уровнями библиотеки: 🔥 Огненный шар (ур. 1), ❄️ Ледяная стена (2), ⚡ Цепная молния (3), 🗿 Каменный страж (4), 💚 Целебный круг (5), ☄️ Метеорит (7). Каждая тренирует свою тему, примеры подбираются по картам в руке.
- 4 постройки (стены, сторожевые башни, библиотека, сокровищница) по 15 уровней, уровни волшебника. Каждое улучшение видно: стены проходят 4 стадии (частокол, камень, камень с железом, магическая крепость), башни и пристройки растут и меняют вид.
- Замок и каждая башня разрушаются по отдельности: трещины, проломы с огнём и дымом, руины.
- Адаптивная сложность: после боя по каждой теме уровень повышается/понижается по точности.
- Защита от накрутки: задания и правильные ответы хранятся на сервере, награду и ману считает сервер; карты дороже заработанной маны или не из колоды боя не засчитываются. Убийства пока берутся из отчёта клиента в пределах состава волны.

**Админ-бот** (только для `ADMIN_IDS`)
- `/admin` — меню на кнопках: темы → уровни → параметры (`−10 −1 +1 +10`, переключатели, выбор таблиц умножения).
- Добавление/удаление уровней темы, 👁 примеры заданий для проверки настроек.
- 🎓 стартовые уровни для каждого класса (можно выключить тему для класса).
- ⚙️ адаптивность: пороги повышения/понижения, окно ответов, число заданий за бой.
- 📊 статистика: игроки, победы, точность и среднее время ответа по темам и уровням.
- 📜 журнал всех изменений, ↩️ `/undo`, 💾 `/export` в JSON и импорт (пришлите файл боту).

## Запуск локально (без Telegram)

Нужен **Node.js 22.13+**.

```bash
npm install
cp .env.example .env      # в Windows: copy .env.example .env
```

В `.env` поставьте `DEV_MODE=1`, затем:

```bash
npm start
```

Откройте http://localhost:3000/?dev=1 — играть можно в обычном браузере (лучше в режиме телефона в DevTools).
`?dev=2`, `?dev=3` — другие тестовые игроки.

## Запуск в Telegram

1. **Бот.** В @BotFather: `/newbot` → получите токен → впишите в `BOT_TOKEN`.
2. **Ваш ID.** Напишите боту `/id` (или @userinfobot) → впишите в `ADMIN_IDS` (через запятую, если админов несколько).
3. **HTTPS-адрес.** Mini App открывается только по HTTPS.
   - Для разработки: `cloudflared tunnel --url http://localhost:3000` или `ngrok http 3000` → получите `https://…` адрес.
   - Для продакшена: VPS + домен + nginx/Caddy (Caddy сам выпускает сертификат), либо Render/Railway/Fly.io.
4. Впишите адрес в `WEBAPP_URL`, поставьте `DEV_MODE=0`, запустите `npm start`.
   Бот сам поставит кнопку «Играть» в меню чата.
5. (По желанию) в @BotFather: `/newapp` — чтобы у игры была прямая ссылка `t.me/ваш_бот/app`.

Данные хранятся в `data/game.db` (SQLite) — делайте бэкап этого файла.

## Как устроена сложность

У каждой темы есть уровни (по умолчанию 5), у каждого уровня — параметры:

| Тема | Параметры |
|---|---|
| Сложение и вычитание | макс. число, действия (`+`, `-`, `+-`), переход через десяток |
| Сравнение | макс. число, выражение слева (`7 + 5 ? 11`) |
| Умножение | какие таблицы, макс. второй множитель, пропущенный множитель, деление |

Ученик стартует с уровня своего класса, дальше уровень меняется автоматически:
≥ 85% верных из последних 12 ответов → выше, ≤ 50% → ниже (пороги настраиваются в боте).

## Арт

Пока картинки нет, игра рисует заглушку кодом. Настоящий арт подключается без правки кода:

1. Сгенерировать картинки по промптам из [`art/PROMPTS.md`](art/PROMPTS.md) (Nano Banana 2 в Gemini). Схема дорожек для фона арены — `art/layout/`, пересоздаётся командой `node tools/arena-layout.mjs`.
2. Сохранить в `art/raw/<имя>` с расширением, которое отдал Gemini (список имён и размеров — `art/assets.js`).
3. Запустить `npm run art`: вырежет пурпурный фон, обрежет и уменьшит картинки, сложит их в `public/art/` и напечатает замеры.

Арт можно добавлять постепенно: чего нет, то остаётся заглушкой.

## Тесты

```bash
npm test
```

Проверяются генератор заданий (ответ всегда среди вариантов, соблюдаются ограничения),
логика боя (мана, рука, башни, карты), расчёт наград и защита от подделки, адаптивность,
проверка подписи Telegram и сценарии админ-бота.

`node tools/screenshots.mjs screenshots-out` прогоняет игру в установленном Chrome на 360×640, 390×844, 412×915
и 1280×800 со своей временной базой и сохраняет скриншоты.
