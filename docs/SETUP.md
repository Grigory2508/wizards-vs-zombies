# Как запустить игру в Telegram — пошагово

Игра живёт в трёх местах, и всё бесплатно:

- **GitHub Pages** — сама игра (то, что видит ребёнок). Выкладывается автоматически.
- **Supabase** — сервер и база: хранит прогресс детей и проверяет ответы.
- **Telegram** — бот, через которого открывается игра, и админка сложности.

Ваш компьютер для работы игры не нужен. Нужно один раз создать аккаунты и скопировать несколько «ключей» в настройки GitHub. Это займёт около 40 минут.

Пока идёте по шагам, держите открытым любой текстовый файл или Заметки: туда будете складывать то, что понадобится потом. Помечено значком 📋.

---

## Часть 1. Telegram: бот и ваш номер

### 1.1. Создать бота
1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите **«Запустить»**.
2. Отправьте `/newbot`.
3. Имя бота (его видят дети): `Волшебники против Зомби`.
4. Адрес бота латиницей, в конце обязательно `bot`, например `wizards_zombies_bot`. Если занят — добавьте цифры.
5. BotFather пришлёт **токен** — длинную строку вида `1234567890:AAH...`.
   - 📋 Сохраните **токен** — это `BOT_TOKEN`.
   - 📋 Сохраните **адрес бота без @** (например `wizards_zombies_bot`) — это `BOT_USERNAME`.

> Токен — пароль бота. Никому его не показывайте и не вставляйте в код или чат — только в «Secrets» на GitHub (часть 3).

### 1.2. Узнать свой номер в Telegram
1. Найдите бота **@userinfobot** и нажмите **«Запустить»**.
2. Он ответит строкой `Id: 123456789`.
   - 📋 Сохраните эти цифры — это `ADMIN_IDS` (по нему бот пускает в админку). Если админов несколько, номера пишутся через запятую: `123456789,987654321`.

## Часть 2. Supabase: сервер и база

### 2.1. Создать проект
1. Откройте **supabase.com** → **Start your project** → войдите через GitHub.
2. Нажмите **New project**.
   - **Name:** `wizards-vs-zombies`
   - **Database Password:** нажмите **Generate a password**, затем скопируйте его и 📋 сохраните (на всякий случай; в настройках ниже он не нужен).
   - **Region:** ближайший к детям, например **Central EU (Frankfurt)**.
   - Тариф — **Free**.
3. Нажмите **Create new project** и подождите 1–2 минуты, пока проект создаётся.

### 2.2. Создать таблицы
1. Откройте в браузере файл схемы базы:
   `https://github.com/Grigory2508/wizards-vs-zombies/blob/main/supabase/migrations/0001_init.sql`
2. Справа над текстом нажмите кнопку **Copy raw file** (значок двух квадратиков). Весь текст скопируется.
3. В Supabase в меню слева выберите **SQL Editor** (значок `>_`).
4. Вставьте текст в большое поле (Ctrl+V) и нажмите **Run** (или Ctrl+Enter).
5. Внизу должно появиться **Success. No rows returned**. Готово: таблицы созданы.

### 2.3. Номер проекта
1. В Supabase слева внизу нажмите **Project Settings** (шестерёнка) → **General**.
2. Найдите **Project ID** — строку из латинских букв, например `abcdefghijklmnopqrst`.
   - 📋 Сохраните — это `SUPABASE_PROJECT_REF`.

### 2.4. Ключ доступа для GitHub
1. Справа вверху нажмите на свой аватар → **Account preferences** → **Access Tokens**.
2. Нажмите **Generate new token**, имя: `github`, создайте.
3. Скопируйте токен (начинается с `sbp_`). Он показывается **один раз**.
   - 📋 Сохраните — это `SUPABASE_ACCESS_TOKEN`.

## Часть 3. GitHub: вписать ключи

### 3.1. Придумать секрет вебхука
Это пароль, по которому сервер узнаёт, что сообщение пришло именно от Telegram. Придумайте 30–40 случайных символов, **только латинские буквы и цифры**, например наберите на клавиатуре что попало: `k3Jd9sPq0zLm2Xv7Rt5Yb8Nw4Hc1Fg6`.
- 📋 Сохраните — это `WEBHOOK_SECRET`.

### 3.2. Секреты (Secrets)
1. Откройте репозиторий `github.com/Grigory2508/wizards-vs-zombies`.
2. Вверху **Settings** → слева **Secrets and variables** → **Actions**.
3. Вкладка **Secrets** → кнопка **New repository secret**. Создайте по очереди три секрета (Name — ровно как написано, Secret — значение из 📋):

| Name | Что вставить |
|---|---|
| `BOT_TOKEN` | токен бота из 1.1 |
| `SUPABASE_ACCESS_TOKEN` | токен `sbp_...` из 2.4 |
| `WEBHOOK_SECRET` | секрет из 3.1 |

### 3.3. Переменные (Variables)
Там же переключитесь на вкладку **Variables** → **New repository variable**. Создайте три переменные:

| Name | Что вставить |
|---|---|
| `SUPABASE_PROJECT_REF` | Project ID из 2.3 |
| `BOT_USERNAME` | адрес бота без @ из 1.1 |
| `ADMIN_IDS` | ваш номер из 1.2 |

## Часть 4. Запустить выкладку

### 4.1. Выложить сервер
1. В репозитории вверху откройте вкладку **Actions**.
2. Слева выберите **Deploy server (Supabase + bot)** → справа **Run workflow** → зелёная кнопка **Run workflow**.
3. Подождите 1–2 минуты. Должна появиться **зелёная галочка** ✅.
   - Если красный крестик ❌ — нажмите на запуск, затем на красный шаг: там написано, чего не хватает. Чаще всего это опечатка в имени секрета или не выполнен SQL из 2.2.

### 4.2. Выложить игру
1. Там же в **Actions** слева выберите **Deploy to GitHub Pages** → **Run workflow** → **Run workflow**.
2. Дождитесь зелёной галочки ✅ (2–3 минуты).

### 4.3. Включить GitHub Pages (один раз)
1. **Settings** → слева **Pages**.
2. В блоке **Build and deployment**: **Source** — **Deploy from a branch**; **Branch** — выберите `gh-pages` и папку `/ (root)` → **Save**.
3. Через 1–2 минуты вверху страницы появится ссылка `https://grigory2508.github.io/wizards-vs-zombies/` — это адрес игры.

## Часть 5. Mini App в BotFather

1. Скачайте картинку для BotFather: `https://github.com/Grigory2508/wizards-vs-zombies/blob/main/docs/botfather-640x360.png` → кнопка **Download raw file** (стрелка вниз).
2. В **@BotFather** отправьте `/newapp` и выберите своего бота.
3. Дальше BotFather спросит по очереди:
   - **Title:** `Волшебники против Зомби`
   - **Description:** `Математика для начальной школы: решай примеры, колдуй заклинания и защищай замок от зомби.`
   - **Photo:** отправьте скачанную картинку 640×360.
   - **GIF:** отправьте `/empty` (без GIF).
   - **URL:** `https://grigory2508.github.io/wizards-vs-zombies/`
   - **Short name:** `play`
4. BotFather пришлёт ссылку вида `https://t.me/wizards_zombies_bot/play`. Это прямая ссылка на игру — её можно отправлять родителям.

## Часть 6. Проверить

1. Откройте своего бота в Telegram и отправьте `/start`. Под ответом будет кнопка **🧙‍♂️ Играть** — игра откроется.
2. Отправьте `/admin` — откроется меню настройки сложности.
3. Сыграйте одну ночь — прогресс сохранится. Закройте игру и откройте снова: всё на месте.

Если игра показывает «Откройте игру через Telegram» — вы открыли ссылку в обычном браузере, а не в Telegram. Так и должно быть: без Telegram прогресс не сохраняется.

---

## Что дальше происходит само

- Любые изменения в игре выкладываются автоматически, как только они попадают в ветку `main` (вкладка **Actions** показывает ход выкладки).
- Раз в три дня GitHub будит базу Supabase, чтобы бесплатный проект не уснул на каникулах.
- Telegram запоминает игру: после обновления закройте её полностью и откройте снова.

## Если что-то не работает

| Что видите | Что делать |
|---|---|
| ❌ в «Deploy server», шаг **Check configuration** | Не задан какой-то секрет или переменная — их имена написаны в сообщении. Проверьте часть 3. |
| ❌ в «Deploy server», шаг **Check API responds**: «База не отвечает» | Не выполнен SQL из 2.2. Выполните его и запустите «Deploy server» снова. |
| ❌ в «Deploy server», шаг **Set up bot** | Неверный `BOT_TOKEN`. Скопируйте токен из BotFather заново. |
| Бот не отвечает | Запустите «Deploy server» ещё раз — он заново подключит бота. |
| Бот не пускает в `/admin` | Номер в `ADMIN_IDS` не совпадает с тем, что прислал @userinfobot. Исправьте переменную и запустите «Deploy server». |
| Игра не открывается, ошибка 404 | Не включены Pages (4.3) или выкладка игры (4.2) ещё не закончилась. |
